# Pavel_4ex — мини-сайт

Адаптивный статический сайт-визитка на русском языке. Не требует сборки или установки зависимостей.

## Страницы

- `index.html` — приветствие, Battlefield 6, Dota 2 и ссылки на Twitch, YouTube, TikTok, Discord, Donation Alerts.
- `pc.html` — характеристики компьютера.
- `styles.css` — адаптивное оформление.

## Публикация

Для GitHub Pages откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните. Сайт будет доступен по адресу `https://pavel4ex.github.io/pavel-4ex-site/`.
